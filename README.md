# 🎮 Games Grátis — Flask + API

Projeto simples feito em **Flask** que consome a API pública do **FreeToGame** para listar jogos gratuitos e exibir uma página de detalhes para cada jogo, incluindo **tradução automática da descrição para português**.

---

## 🚀 Funcionalidades

- 📄 Listagem de jogos gratuitos
- 🖼️ Exibição de thumbnail dos jogos
- 🔍 Página individual para cada jogo
- 🌍 Tradução automática da descrição (EN → PT)
- 🔗 Botão para acessar o jogo oficial
- 🎨 Interface simples com HTML + CSS

---

## 🛠️ Tecnologias utilizadas

- Python 3.11+
- Flask
- Requests
- Googletrans
- HTML5
- CSS3
- API FreeToGame
